# HTML5 Multi-Page Website

A simple multi-page website built using **HTML5**, focusing on semantic structure, navigation, and standard HTML form elements.

## 📄 Pages

The website contains three main pages:

- **Home** (`index.html`) – The main landing page.
- **About** (`about.html`) – Information about the website/project.
- **Contact Us** (`contact.html`) – A structured contact form using standard HTML5 form elements.

## ✨ Features

### Navigation Bar
- Navigation links between all website pages.
- Simple and consistent navigation structure.

### Contact Form

The `contact.html` page contains a semantic HTML5 contact form with:

- **Text Input** – Single-line field for names.
- **Email Input** – Field with built-in email format validation.
- **Number Input** – Field restricted to numeric values.
- **Date Input** – Native date picker for selecting a date.
- **Radio Buttons** – Grouped options allowing a single selection.
- **Checkboxes** – Multiple options can be selected.
- **Dropdown Menu** – Select menu for choosing from predefined options.
- **Text Area** – Multi-line field for longer messages.
- **Submit Button** – Used to submit the form.

## 🏗️ Semantic HTML5 Structure

The pages use semantic HTML5 elements to create a clean and organized structure:

- `<header>`
- `<nav>`
- `<main>`
- `<section>`
- `<footer>`
